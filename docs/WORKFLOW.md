# Submission workflow (from the starter repo)
1. Fork upstream; add all four members as collaborators.
2. `git clone https://github.com/<you>/HFT26-TEAM-11.git && git checkout -b feature/prototype`
3. Small commits from EVERY member, e.g. `feat: add burst merging`.
4. Never push to upstream main. Open a PR from fork main -> upstream main.
5. Open the PR early; keep updating until the code freeze.
6. Only original code written during the hackathon; credit all libraries/models.
